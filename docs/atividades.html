00 / DISCIPLINA

Como usar as práticas

O repositório COMP1 traz um exemplo por semana. A equipe replica a ideia no próprio compilador/, em vez de entregar os exemplos isolados.

git clone https://github.com/sergioaafreitas/COMP1.git
cd "COMP1/semana 01/src"

01 / DIÁRIO

Relação com o compilador

Semana 1 — Hello Flex/Bison

Material: Glossário, guias de ambiente, compilador e interpretador, proposta do trabalho. Prática: hello.l / hello.y.

No projeto G16: Ambiente configurado, Hello World compilando, subset Python → C confirmada.

Semana 2 — Expressões regulares

Material: Guia de ERs no Flex; exemplo que reconhece números e operadores.

No projeto G16: Tokens da subset esboçados em lexer.l; Makefile inspirado na prática.

Semana 3 — Scanner

Material: scanner.l com if/while, ids, números, operadores e comentários C.

No projeto G16: Adaptado para keywords Python, comentários # e tokens consumidos pelo Bison.

Semana 4 — Parser inicial

Material: Expressões com precedência * / sobre + -.

No projeto G16: parser.y da subset, precedência e Makefile integrando lexer + parser.

Semana 5 — Erros sintáticos

Material: Recuperação via error até ;, yyerrok / yyclearin.

No projeto G16: No Python usamos NEWLINE/INDENT em vez de ponto e vírgula. yyerror reporta a linha; recuperação completa ainda é melhoria.

Semana 6 — AST e tabela

Material: ast.c, tabela.c e tipos.h a partir de expressões com identificadores.

No projeto G16: Nós de stmt Python e tabela com escopos; base da semântica e do codegen. Marco P1.

Semana 7 — Semântica

Material: Testes de variável não declarada, redeclaração e tipos.

No projeto G16: Regras no parser.y; mensagens claras para demo P2. Suíte tests/ ainda pode crescer.

Semana 8 — IR / TAC

Material: Protótipo de três endereços na disciplina.

No projeto G16: A equipe optou por emitir C direto da AST, sem TAC no binário atual.

Semana 9 — Otimização

Material: Constant folding sobre a AST.

No projeto G16: Não está no gerador atual; documentada como melhoria.

Semana 10 — Código final

Material: Exemplo Java mínimo → bitcode textual.

No projeto G16: No nosso caso o alvo é C: percorrer AST e emitir saida.c, depois gcc.
