00 / FUNDAMENTOS

O que são tokens?

O analisador léxico lê o código caractere a caractere e devolve tokens para o Bison. O wrapper yylex drena uma fila usada para INDENT/DEDENT.

PYTHONentrada
x = 10
print(x)
TOKENSsimplificado
IDENTIFIER(x) ATRIBUES NUMBER(10) NEWLINE
PRINT LPAREN IDENTIFIER(x) RPAREN NEWLINE

04 / TOKENS

Literais

TokenPadrãoValor semântico
NUMBER[0-9]+yylval.inteiro
FLOAT[0-9]+\.[0-9]+yylval.real
STRINGaspas simples ou duplaslexema copiado, incluindo as aspas
BOOLEANTrue/False1 ou 0 em yylval.inteiro
Compatibilidade

Identificadores true e false ainda viram BOOLEAN. O padrão Python oficial é True/False.

Strings

O lexer não trata escapes nem string não terminada com mensagem específica: aspas sem fechamento tendem a consumir o restante ou gerar caractere inválido.

05 / TOKENS

Identificadores

Padrão [a-zA-Z_][a-zA-Z0-9_]*, depois das palavras-chave. O texto vai para yylval.texto.

  • Válidos: x, soma, _var.
  • Inválidos: 1var, var-nome.

06 / PYTHON

INDENT, DEDENT e NEWLINE

No início de linha (estado BOL) o lexer mede espaços/tabs (tab = 4), compara com uma pilha e enfileira INDENT ou um ou mais DEDENT. Linhas vazias e comentários no BOL são ignorados. No EOF a indentação volta a zero.

Erros

Indentação inconsistente ou profunda demais é reportada em stderr, com o número da linha.

07 / IGNORADOS

Comentários e espaços

Comentários #... e espaços/tabs no meio da linha não geram token. \n gera NEWLINE e volta ao estado BOL.

08 / ERROS

Caracteres inválidos

A regra coringa imprime Caractere invalido na linha N: ... e continua, para reportar vários erros na mesma execução.

09 / INTEGRAÇÃO

Integração com o Bison

Tokens declarados em parser.y com %token. Fluxo: Python → Flex → tokens → Bison → AST → semântica → gerarCodigoC.

%token PRINT IF ELSE WHILE DEF RETURN
%token COLON NEWLINE COMMA INDENT DEDENT
%token PLUS MINUS TIMES DIVIDE
%token EQ NEQ LEQ GEQ LT GT ATRIBUES
