00 / MÉTODO

Como a equipe trabalha

Cada sprint tem objetivo, tarefas, issues, acompanhamento, problemas e documentação. Antes da reunião de quarta, cada pessoa atualiza issues, commits e PRs.

A reunião verifica o feito, atrasos, impedimentos, progresso, próximas atividades, GitHub Project e decisões técnicas.
